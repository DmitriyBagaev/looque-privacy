# Политика конфиденциальности Looque

Действует с 22 октября 2026 года.

Looque каждое утро подсказывает, что надеть из своего гардероба, и показывает образ на человеке. Приложение делает Дмитрий Багаев. Связаться: feedback@bagaev.design.

**Что хранится на телефоне.** Вещи и их фото, люди для примерки и их фото, готовые примерки, настройки. Всё это лежит в памяти приложения на твоём телефоне. Аккаунтов и своего сервера у приложения нет. Если в приложении включена копия в iCloud, те же данные хранятся в твоём личном iCloud: доступ к ним есть только у тебя, у разработчика его нет.

**Что уходит с телефона и зачем.**

1. *Примерка — Google Gemini API.* Только после твоего разрешения и только когда ты сам просишь нарисовать картинку («Примерить», «Ещё раз», портрет). Отправляются фото вещей образа и портрет того, на ком примеряем. Когда ты добавляешь себя — твоё фото в полный рост и, если добавил, крупный план лица. После примерки в Google уходит и сама картинка, чтобы найти на ней вещи. По условиям Google для платного Gemini API запросы не используются для улучшения продуктов Google; Google хранит их ограниченное время, чтобы находить нарушения своих правил. Условия Google: https://ai.google.dev/gemini-api/terms
2. *Погода.* Примерные координаты (точность около 1 км) или выбранный город уходят в Apple Weather, а если она не отвечает — в Open-Meteo или MET Norway. Название города по координатам определяет Apple. Поиск города по названию идёт через Open-Meteo.
3. *TestFlight.* Если ты отправляешь отзыв или отчёт о сбое, Apple передаёт его разработчику.

**Чего нет.** Рекламы, аналитики, слежки за тобой в других приложениях, продажи данных и передачи их кому-то ещё.

**Доступы.** Камера — снять вещь или себя. Фото — выбрать снимок. Геолокация — погода там, где ты. Каждый доступ iPhone спрашивает отдельно, и его можно выключить в Настройках.

**Как удалить данные.** Удалённое 30 дней лежит в «Недавно удалённых», потом стирается само; оттуда можно стереть и сразу. Удаление приложения стирает с телефона всё, кроме счётчика расходов на примерки: в нём только суммы по месяцам, и он лежит в связке ключей iPhone, чтобы месячный лимит не обнулялся при переустановке. Копию в iCloud можно удалить в Настройках iPhone → твоё имя → iCloud → Хранилище.

**Возраст.** Приложение для тех, кому есть 18: этого требуют условия Google для Gemini API.

**Изменения.** Если политика изменится, новая версия появится по этому же адресу с новой датой.
